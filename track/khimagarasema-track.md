# «Від зерна — до врожаю» — трек для Хімагарасема

Гімн для відео, рілсів, презентацій і виставок. Тема — насіння соняшника та кукурудзи:
від зернини в долоні до золотого поля. Настрій — світлий, енергійний, з українським колоритом.

---

## 1. Музична концепція

| Параметр | Значення |
|---|---|
| Жанр | Українська фолктроніка / поп-гімн (сучасний етно-поп з електронікою) |
| Темп | 118–122 BPM — підходить під динамічний монтаж: дрон над полем, таймлапс сходів, техніка в полі |
| Тональність | Мажор (наприклад, A major) — відчуття сонця і росту |
| Вокал | Жіночий головний вокал + чоловічий/хоровий бек у приспіві (як «гуртом у полі») |
| Інструменти | Сопілка або флейта (головний мотив), бубон/етно-перкусія, яскраві синт-плаки, бочка 4/4, баси, струнні на фіналі |
| Тривалість | Повна версія ~2:45–3:10, плюс короткі нарізки 15 с і 30 с |

**Драматургія = ріст рослини:**
- Інтро (тиша, світанок, одна сопілка) → **насіння в землі**
- Куплет 1 (легкий біт) → **сходи**
- Приспів (повний звук) → **поле в цвіту**
- Брідж (майже a cappella, наростання) → **очікування врожаю**
- Фінальний приспів (хор + струнні) → **жнива, перемога**

Так музика сама «росте» разом з картинкою — під таймлапс сходів це працює ідеально.

## 3. Як згенерувати трек (Suno / Udio)

1. Відкрийте Suno (suno.com) → **Create** → увімкніть **Custom**.
2. У поле **Lyrics** вставте весь текст з розділу 2 (разом із мітками `[Verse]`, `[Chorus]` тощо).
3. У поле **Style of Music** вставте один із промптів нижче.
4. **Title:** `Від зерна — до врожаю`
5. Згенеруйте 4–6 варіантів, виберіть найкращий; вдалий фрагмент можна продовжити через **Extend**.

### Промпт стилю — основний (рекомендовано)
```
Ukrainian folktronica anthem, uplifting, sunny, 120 BPM, female lead vocal, folk choir harmonies, sopilka flute hook, ethnic percussion, bright synth plucks, four-on-the-floor kick, big festival chorus, cinematic strings finale
```

### Альтернатива — сучасний поп для TikTok/Reels
```
Ukrainian pop, catchy summer hit, 122 BPM, energetic female vocal, punchy drums, deep bass, folk flute riff, stadium chant chorus, radio-ready, positive
```

### Альтернатива — епічна, для корпоративного відео / виставки
```
Epic cinematic Ukrainian folk, orchestral, 100 BPM, powerful female vocal, male choir, ethnic drums, strings and brass, slow build to triumphant chorus, inspiring
```

### Інструментал (фон під відео без слів)
Увімкніть **Instrumental** і використайте:
```
Uplifting Ukrainian folktronica instrumental, 120 BPM, sopilka flute melody, ethnic percussion, warm synth pads, plucks, four-on-the-floor, corporate positive, sunrise over fields, background for video
```

### Порада щодо назви компанії
Якщо ШІ неправильно наголошує або «ковтає» назву, напишіть її в тексті по складах
з наголосом, наприклад `Хі-ма-га-ра-се́-ма`, або великими літерами у потрібному складі.
Згенеруйте кілька варіантів і залиште той, де назва звучить найчіткіше.

## 4. Короткі версії для соцмереж

**Джингл 10–15 с (заставка, кінець відео, реклама):**
```
[Chorus]
Соняшник — до сонця, кукурудза — в небо,
Хімагарасема — все, що полю треба!
```

**Нарізка 30 с (Reels / TikTok / Shorts):** беріть з повної версії відрізок
**Pre-Chorus + Chorus** — він має наростання і вибух, під який зручно ставити
перехід «сходи → поле в цвіту».

**Слоган для підписів і хештегів:**
- «Від зерна — до врожаю»
- «Сила в кожній зернині»
- `#Хімагарасема #ВідЗернаДоВрожаю #СилаВКожнійЗернині #соняшник #кукурудза #насіння`

## 5. Ідеї монтажу під трек

| Частина треку | Картинка |
|---|---|
| Інтро | Світанок над полем, туман, макро — зернина в долоні |
| Куплет 1 | Сівба, сівалка в полі, перші сходи (таймлапс) |
| Pre-Chorus | Швидкі склейки на біт: дощ, сонце, листя росте |
| Приспів | Дрон над соняшниковим полем, качани кукурудзи, усмішки агрономів |
| Куплет 2 | Липень: соняшники повертають голови, огляд посівів |
| Брідж | Повільно: обличчя людей, руки в землі, прапор над полем |
| Фінальний приспів | Жнива, комбайни, зерно сиплеться в кузов, команда разом |
| Аутро | Логотип Хімагарасема + слоган «Від зерна — до врожаю» |

## 6. Права та використання

- На платних тарифах Suno/Udio комерційне використання згенерованих треків дозволене —
  перевірте умови свого тарифу перед публікацією в рекламі.
- Текст пісні вище — оригінальний, створений спеціально для Хімагарасема, його можна
  вільно змінювати (назви сортів, регіон, рік тощо).
